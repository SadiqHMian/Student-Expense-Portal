# Student-Expense-Portal
End-to-End Portal
An end-to-end web application built
### Features:
- **Backend (Jupyter Notebook):** Modular Python functions, CSV/JSON file handling, exception handling, and a terminal `while True` loop.
- **Frontend (Streamlit):** Modern dark-mode UI, interactive Plotly charts, budget alerts, and smart insights.

### How to run the Frontend:
1. Install requirements: `pip install streamlit pandas plotly`
2. Run the app: `streamlit run app.py`
